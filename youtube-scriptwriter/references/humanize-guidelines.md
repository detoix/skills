# Humanize Guidelines

These guidelines help the scriptwriter produce narration that sounds like a real person talking, not an AI generating text. The same principles apply in every language; concrete examples are given in English and Polish.

The lists below are **soft avoids**, not hard bans. A word from the avoid list is acceptable when it is genuinely the best fit for the context, but defaulting to these words is a strong signal the script sounds artificial. When in doubt, pick the simpler, more conversational alternative.

## Vocabulary to Avoid

### English

| Category | Strongly Avoid | Prefer Instead |
|---|---|---|
| **Verbs** | delve, leverage, utilize, harness, streamline, underscore, embark, facilitate, optimize, foster, elevate, navigate (metaphorical) | dig into, use, tap into, simplify, highlight, start, help, improve, boost, work through |
| **Adjectives** | pivotal, robust, innovative, seamless, cutting-edge, intricate, comprehensive, vibrant, unparalleled, groundbreaking, game-changing | key, solid, new, smooth, latest, detailed, full, lively, unmatched, big, important |
| **Nouns** | landscape (metaphorical), realm, tapestry, synergy, testament, underpinnings, paradigm, ecosystem, framework, treasure trove, journey (metaphorical) | space, area, mix, teamwork, proof, basics, model, system, setup, goldmine, process |
| **Transitions** | Furthermore, Moreover, Consequently, Notably, Importantly, Thus, Accordingly, Nonetheless, Subsequently, In conclusion | Plus, Also, So, On top of that, That said, Still, Then, Bottom line |
| **Cliché openers** | "In today's [adj] world/landscape," "Let's dive in," "Without further ado," "In this video we will" | *(just start the content — no preamble)* |

### Polish (Polski)

| Kategoria | Unikaj | Preferuj |
|---|---|---|
| **Czasowniki** | zgłębiać (nadużywane), wykorzystywać (w sensie "leverage"), optymalizować (nadużywane), usprawnić (nadużywane), wdrażać (gdy niepotrzebne), eksplorować | sprawdzić, użyć, poprawić, przyspieszyć, przetestować |
| **Przymiotniki** | innowacyjny, kluczowy (nadużywane), kompleksowy, bezprecedensowy, przełomowy, rewolucyjny, dynamiczny (jako filler) | nowy, ważny, pełny, pierwszy taki, duży, szybki |
| **Rzeczowniki** | ekosystem (metaforycznie), paradygmat, synergia, framework (kalk), landscape/krajobraz (metaforycznie), transformacja (jako buzzword) | system, model, współpraca, struktura, przestrzeń, zmiana |
| **Łączniki** | Ponadto, Co więcej, W konsekwencji, Warto zauważyć, Tym samym, Niemniej jednak | No i, Poza tym, Więc, A tak w ogóle, I jeszcze jedno, Ale uwaga |
| **Szablonowe otwarcia** | "W dzisiejszym dynamicznym świecie…," "Bez zbędnego wstępu…," "W tym filmie omówimy…" | *(po prostu zacznij od tematu)* |

## Rewrite Examples

### English

| AI Default | Human Rewrite |
|---|---|
| "In today's rapidly evolving digital landscape…" | "Things are moving fast right now." |
| "Furthermore, it is important to note that…" | "Plus — and this matters —" |
| "Let's delve into the intricacies of…" | "Let's break this down." |
| "This serves as a testament to…" | "That proves it." |
| "Leveraging cutting-edge innovations…" | "Using the latest tech…" |
| "It offers a seamless and robust experience" | "It just works. Reliably." |
| "Without further ado, let's dive in" | *(just start the content)* |
| "This is a game-changing paradigm shift" | "This changes everything." |
| "Navigate the complexities of modern…" | "Figure out how to deal with…" |

### Polish (Polski)

| Brzmi jak AI | Brzmi jak człowiek |
|---|---|
| "W dzisiejszym dynamicznym świecie technologii…" | "Technologia pędzi do przodu." |
| "Ponadto warto zauważyć, że…" | "No i jeszcze jedno —" |
| "Zgłębmy zawiłości tego tematu…" | "Rozpracujmy to." |
| "To stanowi doskonały przykład…" | "To najlepszy dowód." |
| "Wykorzystując innowacyjne rozwiązania…" | "Używając najnowszych narzędzi…" |
| "Oferuje bezproblemowe i kompleksowe doświadczenie" | "Po prostu działa. Bez niespodzianek." |
| "Bez zbędnego wstępu, zaczynajmy" | *(po prostu zacznij)* |
| "To przełomowa zmiana paradygmatu" | "To zmienia zasady gry." |
| "Eksplorując ekosystem nowoczesnych rozwiązań…" | "Sprawdźmy, co jest teraz dostępne…" |

## The Read-Aloud Test

Before finalizing any script, mentally read every `narration` line out loud. Apply these checks:

1. **Would you actually say this on camera?** If a phrase would make you cringe or sound like a corporate keynote, rewrite it.
2. **Does the rhythm feel natural?** If you're running out of breath mid-sentence, it's too long. If every sentence feels the same length, the rhythm is too uniform.
3. **Is it specific?** Vague, impressive-sounding generalizations ("innovative solutions for the modern era") carry zero information. Replace them with concrete details.
4. **Does it have personality?** A script with no opinions, no questions, and no surprises is a script that sounds like a machine wrote it.
